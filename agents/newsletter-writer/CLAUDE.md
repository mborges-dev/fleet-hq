```

🔴 DESTAQUE DA SEMANA
[Regulatory or market news — 150 words]

[Vendor update — new / closed / warning letter — 100 words]

[Compound brief — 100 words, educational]

[3 links to ExampleBrand articles + 2 external useful links]

[1 verified vendor, honest context, affiliate link from affiliate-ops]
```

## Cadence (weekly, drafted Thursdays 12:00, sent 18:00)
1. Read week's outputs from: `brand-editor` (3 latest articles),
   `regulatory-watcher` (this week's events), `vendor-rater` (latest
   ratings), `affiliate-ops` (which sponsor slot this week).
2. Draft edition in `editions/<YYYY-WW>.md`.
3. Send to human for 15min review.
4. Schedule send via Beehiiv API for Thu 18h.
